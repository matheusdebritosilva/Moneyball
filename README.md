Plataforma web para gerenciar estatísticas de jogadores e equipes de basquete: dashboard, rankings, comparação de jogadores, importação/exportação de dados e controle de usuários.

Estrutura do projeto

├── index.html          # Dashboard
├── home.html            # Página inicial / Hall of Fame
├── login.html            # Autenticação
├── jogadores.html         # Lista e cadastro de jogadores
├── equipes.html           # Lista e cadastro de equipes
├── comparar.html          # Comparação entre jogadores
├── ranking.html           # Ranking por categoria
├── importar.html          # Importação de CSV
├── exportar.html          # Exportação de relatórios
├── usuarios.html          # Gestão de usuários (Admin)
├── script.js              # Lógica do front-end
├── style.css               # Estilos
├── api.php                 # API (login, sessão, sincronização com o banco)
├── conexao.php              # Conexão PDO simples (auxiliar)
└── banco_de_dados.sql        # Script de criação do banco
```

Tecnologias

- HTML, CSS e JavaScript puro no front-end
- PHP no back-end
- MySQL como banco de dados
